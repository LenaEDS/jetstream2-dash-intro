A Five-Minute Introduction to Jetstream2 for Interactive Dashboards
===================================================================

This is a standalone, five-minute talk introducing **Jetstream2** — the
NSF-funded research cloud — to researchers who build interactive scientific
dashboards (for example, with `Plotly Dash <https://plotly.com/python/dash/>`_).

It was prepared for the *Building Interactive Scientific Dashboards in the
Cloud with Plotly Dash* workshop presented at
`TACCSTER <https://tacc.utexas.edu/taccster/2026/>`_, but it stands on its
own: each page below is one slide, with suggested speaker notes included, and
the whole talk runs about **5 minutes** (~700 spoken words).
