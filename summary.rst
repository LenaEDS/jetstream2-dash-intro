Optional extras (if you have ~30 s to spare)
--------------------------------------------

- One-liner to hammer the "free" point: "Your university account logs in, the
  NSF pays the bill, and the only budget line is your allocation's credits —
  which a shelved, idle VM doesn't consume."
- If someone asks *"how is this different from just using the cluster's GPU
  server?"*: batch HPC gives you CPU-hours on a queue; a Dash app needs a
  *named, addressable machine that never goes away* — that's the cloud model.
